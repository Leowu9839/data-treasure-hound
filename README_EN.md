## The Problem

- You're doing market research, but all public data is stale and surface-level.
- You want to validate a hypothesis but don't know where to find evidence beyond surveys.
- You sense there's data backing a phenomenon, but you can't locate the source.
- You read others' analysis reports with wildly exotic data sources — where did they get them?

**The truth: The data exists. You're just trapped in your own industry perspective.**

---

## What This Is

**Data Hound** is a cross-domain data discovery AI Skill.

It doesn't help you search papers, teach you Python web scraping, or recommend data platforms. What it does: **Uses anthropological fieldwork methodology to sniff out structurally resonant data sources in domains seemingly unrelated to your need.**

### Core Methodology: Two Kinds of "Distance"

```
Real Need ──Socratic Deconstruction──▶ Physical Traces ──De-functionalization──▶ Structural Conflict
                                                      │
                                                      ▼
                                              【PO Word】Cross-domain random word
                                                      │
                                                      ▼
                                              Thought Web ≥5 chains × ≥5 steps
                                                      │
                                                      ▼
                                              Black-box Packaging + Zero-base Reconstruction
                                                      │
                                                      ▼
                                              Multiple Candidates + Five-pit Verification
```

**You search for neighbors in semantic space. The Hound searches for distant relatives on the purpose chain — this is what AI can do that humans cannot.**

### Analogy Depth Levels

| Level | Name | Example |
|:----:|------|---------|
| L1 | Same-domain direct substitute | Survey A → Survey B |
| L2 | Same-domain different method | Survey → Behavioral logs |
| L3 | Cross-domain isomorphism | Consumption data → Health data with same patterns |
| L4 | System-level analogy | Biological immune system → Cybersecurity system |

> **When L4 candidates = 0, the Hound goes back to work.** Until it finds a source that surprises you.

## Real Example

**Need**: "I want to understand the real activity level of nighttime economy in a tier-2 city."

**Typical approach**: Search statistical bureau data, read news reports, send surveys.

**The Hound's sniffing path**:
1. **Socratic Deconstruction**: What traces do people unconsciously leave when going out at night? → Mobile base station positioning, power bank rental records, ride-hailing night order heat, garbage collection frequency, streetlight electricity usage curves
2. **De-functionalization**: 「Nighttime population density」×「Consumption willingness intensity」
3. **PO Word**: Throw "bat" → ultrasonic echolocation → city WiFi probe signals → commercial district foot traffic heat maps
4. **Thought web endpoints**: Telecom base station data, shared bike dispatch records, delivery rider night distribution heat, power grid load curves
5. **Candidate output**:
   - L3: Meituan/Ele.me nighttime order heat maps (publicly available)
   - L3: Didi Chuxing nighttime destination distribution report (quarterly public)
   - L4: State Grid city power load curves (reverse-engineering commercial activity)

**User feedback**: "I never thought of these data sources, but they do answer my question."
