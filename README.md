## 你是不是也这样？

- 做市场调研，发现公开数据都太陈旧、太表层
- 想验证一个假设，却不知道除了问卷还能去哪找证据
- 明明感觉某个现象有数据支撑，就是找不到来源
- 看别人的分析报告，数据来源一个比一个野——他们到底从哪搞到的？

**真相：数据不是没有，是你被自己的行业视角困住了。**

---

## 这是什么

**数据宝藏猎犬（Data Hound）** 是一个跨域数据发现 AI Skill。

它不帮你搜论文、不教你用Python爬虫、不给你推荐数据平台。它做的是：**用人类学田野调查的方法论，在和你需求"八竿子打不着"的领域里，嗅出结构共振的数据源。**

### 核心方法论：两种"远"

```
真实需求 ──苏格拉底拆解──▶ 物理痕迹 ──去功能化──▶ 结构冲突
                                          │
                                          ▼
                                    【PO掷词】跨域随机词
                                          │
                                          ▼
                                    思维网 ≥5链×≥5步
                                          │
                                          ▼
                                    黑箱打包 + 零基重构
                                          │
                                          ▼
                                    多候选 + 五坑倒查
```

**你在语义空间找近邻，猎犬在目的链上找远亲——这是 AI 能做而人不能的根本原因。**

### 类比深度等级

| 等级 | 名称 | 示例 |
|:----:|------|------|
| L1 | 同域直接替代 | A问卷 → B问卷 |
| L2 | 同域异法 | 问卷 → 行为日志 |
| L3 | 跨域同构 | 消费数据 → 健康数据中相同模式 |
| L4 | 系统级类比 | 生物免疫系统 → 网络安全系统 |

> **L4 候选数 = 0 时，猎犬会返工。** 直到找到让你意外的数据源为止。

## 真实案例

**需求**："我想了解某二线城市夜经济的真实活跃度。"

**普通做法**：搜统计局数据、看新闻报告、发问卷。

**猎犬的嗅探路径**：
1. **苏格拉底拆解**：人在夜间外出消费时，无意识留下了什么痕迹？→ 手机基站定位、充电宝租借记录、网约车夜间订单热力、垃圾清运频次、路灯用电量曲线
2. **去功能化**：「夜间人员密度」×「消费意愿强度」
3. **PO掷词**：掷入"蝙蝠"→ 超声波回声定位 → 城市WiFi探针信号 → 商圈人流热力图
4. **思维网末端**：电信基站数据、共享单车调度记录、外卖骑手夜间配送热力、电力负荷曲线
5. **候选输出**：
   - L3：美团/饿了么夜间订单热力图（公开可获取）
   - L3：滴滴出行夜间目的地分布报告（季度公开）
   - L4：国家电网城市电力负荷曲线（反推商业活跃度）

**用户反馈**："这些数据源我从来没想过，但它们确实能回答我的问题。"
